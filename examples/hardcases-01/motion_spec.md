# 动作分镜 v2：【商业狠人图鉴 01】查理·芒格（59.7s）

时间都是配音里那个字被读到的时刻（timeline.json）。每一拍写：焦点 → 动作（从哪、多久、缓动、过冲、模糊、碰到什么、怎么走）→ 主角在干什么。

## 一、这个系列的动作语法（每期通用）

| 语义 | 怎么动 | 参数 |
|---|---|---|
| 坏事 | **从上面砸下来**，砸中时整屏震一下，主角被砸得后仰 | 从屏外 0.22s 加速落下；落地压扁 sy .85（0.06s）→ 回弹 1.03 → 0.2s 停稳；屏幕震 10px，0.25s 衰减；落点扬 6–8 粒灰；thud |
| 好事 / 翻盘 | **从下面弹上来**，过冲再回落 | 0.3s，过冲 12%（back），之后 ±4° 晃 0.6s 衰减 |
| 数字 | 拍在牌子上 / 翻牌器一位位翻 | 翻牌器每位 0.06s，红色是关键数字 |
| 贴条（人名、地名、结论） | 转着拍上去 | 从 −40°、×1.6 → 0°、×1，0.25s 快进慢停；之后 0.15s 小回摆 |
| 甩进来的东西 | 0.12s 从屏外飞到位，带 20→0 的方向模糊，再阻尼摆 1s | 角度 = A·e^(−2.5τ)·cos(7.2τ)（对临 v1 量的） |
| 离场 | **从不凭空消失**：被推走、被扫走、自己走掉、被吹走 | 离场比进场快 30% |
| 人物换姿势 | 换图的那一帧压扁一下、跳 20px | sy .92→1，0.15s；平时有呼吸（sy 1±.01，0.8Hz） |
| 走路 | 上下颠 + 前后晃 | 颠 14px、12Hz，晃 ±3° |
| **换场（系列签名）** | **一张巨牌翻过整屏**：牌从一侧甩进来，转到正对镜头时盖满屏，背面就是下一场 | 0.35s，最快处换场，带横向模糊 |
