# 例子：《商业狠人图鉴 01》查理·芒格（59.7 秒，用户给的整条正式配音）

"怎么做过一次"，不是模板。五个版本（1、2、3、4、4.1），用户各说了一句，每句都对应一条现在写进 skill 的做法。

| 文件 | 是什么 |
|---|---|
| `motion_spec.md` | 第 2 版的动作分镜：系列动作语法、角色表、约 60 拍逐拍的动作参数、换场表 |
| `staging.md` | 第 3 版的舞台调度导演表：牌桌分区、三张牌的账本、地图上的红 ×、每样东西凭什么在、凭什么走 |
| `attention.md` | 第 4 / 4.1 版的导演表：注意力层级（特效盖内容的四个原因、改法）、开头恢复、9:16 安全区、字幕字体 |
| `near_misses.jpg` | 同一时刻的第 1 / 2 / 3 版（开头、封面卡、归了前妻、攒下上百亿、列成清单） |
| `near_misses_v4.jpg` | 同一时刻的第 3 版 / 第 4.1 版（开头一样；牌桌、地图、结尾改了什么） |
| `contact.jpg` | 第 3 版每 2 秒一帧 |
| `contact_v41.jpg` | 第 4.1 版每 2 秒一帧 |

## 各版错在哪

| 版 | 用户原话 | 根因 | 改了什么 |
|---|---|---|---|
| 1 | "像一个半成品……人物竟然只有一个……道具转场入场这些啥动画都没有" | 导演表写了"发生什么"，没写"怎么动"；原创没有原片可量，全落回默认：从零放大弹出来、直线滑进来、到位不动；文案里的人拿道具顶替 | 先写动作表；定动作语法（坏事从上砸、好事从下弹、贴条转着拍、离场被带走）；8 个角色上场；主角 10 个姿势 |
| 2 | "场景页面比较杂乱……为了堆砌而堆砌" | 东西临时找个空位放；积累没有意义（和后文无关的 2/7/3、每件坏事各带一套道具）；留着或走掉和故事无关 | （先是机械加退场，被打断："从导演的角度出发，而不是为了精简而精简"） |
| 3 | "也行吧 够了"（之后又看了一遍："被特效覆盖了内容，感觉不是在看内容而是看特效去了"） | — | 每场固定分区：主角位 / 三个牌位（翻开的一直留着 = 好几次）/ 小戏区 / 字位；54 岁的事故演在他脸上；"换个人"真的换一个人；筹码从三张烂牌上长出来；地图上绕开的坑留下红 ×，"列成清单"时一路的 × 收进清单 |
| 4 | "被特效覆盖了内容……看特效去了" | 照风格的数字往上堆（0.4–0.6s 一个事件、推拉 55–80%/s），没有注意力预算：没有字幕、二十多个关键词各在一处并转 40° 拍进来；地图满饱和、芒格只占屏高 1/6；约 40 次镜头小抽动各配一声"呼"、每砸一样东西震一次屏、两次整屏糊的甩镜；18 张纸、16 枚金币 | 固定一条字幕；关键词小幅进场；震屏降到 1/3、小抽动删一半、推拉不配"呼"、地图甩镜改成不糊的摇；地图压暗、芒格放大三成；牌放大抬高。调度不动。顺手删了 54 岁那镜看起来像眼罩的黑圆 |
| 4.1 | "开头其实可以不用换你懂吗""9：16的比例哈 适合短视频的啊""字幕字体也选择合适的哈" | 第 4 版把减法一刀切到了全片，开头钩子也减了；字幕放在 y≈1590，正压在抖音标题区；字幕用了 900 的粗体，小字号发糊 | 开头 0–8.6s 恢复第 3 版（逐帧灰度差 ≤1.6，25 个音效一致）；按抖音界面排版（字幕 y≈1400，牌桌整场上抬 200，牌、小戏区、"烂人"、路碑、结尾巴菲特都离开右侧按钮列）；字幕换思源黑体 Bold 62px 白字粗黑描边 |

## 量出来的数（第 3 版）

| | 这一版 | 参考 |
|---|---|---|
| 音画对齐（从成片识别） | 中位 0ms，>150ms 的 5% | ±100ms |
| 推拉幅度 / 几乎不动 | 62%/s / 27% | 55–80 / 22–37% |
| 音效 | 每分钟 137 个 | 120–144 |

第 4.1 版：推拉幅度 65%/s、几乎不动 37%（开头和转场撑起幅度，讲事段落停得更多）；音效每分钟 115 个；时长、响度、峰值硬项通过。音画对齐这次没量成（`verify.py --sync` 加载语音识别模型时进程直接退出），配音和时间线没改，沿用第 3 版的 0ms。

## 没做到的

- ~~`staging.md` 写了开头的复印纸从 18 张减到 6 张~~：第 4 版真减了，用户说"开头其实可以不用换"——满天飞的纸就是在演"全世界都在抄"，盖住脸一下没关系。第 4.1 版恢复 18 张。开头钩子不按讲事段落的规矩减。
- 地图那段信息比牌桌密，节奏用户没单独评价。

## 不要搬的

收藏卡封面、牌桌、三张牌、地图旅人、骷髅钉——都是这一期的答案。"商业狠人图鉴"系列每期可以沿用的只有：收藏卡当封面（系列识别）、动作语法、"一手牌"式的账本位思路（换成那一期主角自己的东西）。
