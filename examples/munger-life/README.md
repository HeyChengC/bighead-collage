## 这条片要观众带走什么

一个杂货店少年，绕过一段最难的日子，靠"反过来想"，成了老板孙子的老师；差 34 天到一百岁。
画面记忆：倒着翻过来的芒格、头上挂着老板家招牌的巴菲特、没点蜡烛的百岁蛋糕。

## 判断是怎么落下来的

**1 谁带着观众走。** 讲一件事时由物件带（参考 v1 的钞票、数字、黑板）；讲一个人的一生，人就是那样东西。所以芒格每次换场都在画面里：同一个位置，或者被镜头跟着走。每场都另有他之外的东西在动（戒指滚走、招牌荡下、日历翻页），不然就是人物 PPT。

**2 八个换场，每个都答得出"凭什么接"：**

| 换场 | 带过去的东西 | 换场动作为什么讲得通 |
|---|---|---|
| 明信片 → 杂货店 | 少年 | 他在明信片的街上走进一扇门，镜头跟着推进门里，门里就是店（推进的最快处换场） |
| 店里 → 法学院 | 走路的芒格 | 他走出店，一扇窄门板从前景扫过；门板左边还是店，右边已是法学院，走着的人从少年换成大人（同一个走向） |
| 法学院 → 低谷 | 芒格本人，原地不动 | 圆从他胸口长开，同一个人、同一个位置变成黑白 |
| 低谷 → 反过来想 | 芒格本人 | 说到"反过来"，整个灰色世界翻过去掉下，他翻一个跟头，颜色回来（字也从倒着转正） |
| 反过来想 → 晚餐桌 | 芒格本人 | 牛皮纸整张滑走，人留在原处，背后露出桌子 |
| 认识 → 教 → 去世 | 同一张桌子 | 后三分之一不换场：黑板落下、日历翻页、他起身离开、蛋糕滑到他的空位前 |

**3 动作落在字上。** 每个换场、每个物件动作、每个镜头到位，都卡在它要演的那个词上："杂货店"时店展开、"却"时文凭撕开、"反过来"时世界翻转、"走了"时他起身。时间全部用 `at(句, 词)` 取，没有手写秒数。

**4 节奏按中文观众翻译。** 参考片一场 1.2–3 秒；这里一场 2–6 秒、段落间停 0.35–0.55 秒，场内的事件仍然 0.4–0.6 秒一个。镜头几乎不动的时间约 57%（参考 22–37%），用户认可。

**5 镜头走曲线。** 每场 1–2 个宽的推拉（推拉幅度 90 分位 64.7%/s，参考 57.6–79.5），推完停一停；出场那段不停，速度带进转场。

## 不要搬的

- 明信片开场、门板擦过、倒挂翻跟头、晚餐桌收尾——这些是这条片的答案。下一条片换了人，就从他自己的物件里找（他的发明、他的球场、他的实验室）。
- 招牌回扣（S03 的招牌在 S07 挂到巴菲特头上）是因为这个题目里"老板的孙子"恰好就是巴菲特；不是每条片都要回扣。
