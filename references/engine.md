# 引擎：stage.js

画面是一个纯函数：`seek(t)` 只依赖 t。舞台是 1080×1920 的逻辑坐标（左上原点），按视口缩放。
工程用 `python scripts/new_film.py <目录>` 建，`a/` 里是 stage.js、look.css、字体。**工程必须自带这些文件**（渲染器只服务工程目录，`../` 外的文件会 404）。

## 基本单位

```js
const {scene, word, row, sfx, TX, LOOK, at, beat, W, H} = STAGE;

// 一场 = 一个小舞台。t0/t1 是这场在屏上的时间；bg 是底色（CSS）；cam 是相机关键帧
const A = scene({t0: 0, t1: beat('s02').end, bg: '#7cc4ee',
  cam: {z: [[0, 1.3], [1.6, 1.0, 'out']], y: [[0, -1000], [1.6, 0, 'out']], x: 0},
  whips: []});                      // 甩镜时间窗，只有这里会加横向运动模糊

// 层：图片或 html。x,y 是锚点(ax,ay)在舞台上的位置；s 缩放、r 旋转、o 透明度、blur 模糊；都可以是关键帧
A.add({img: 'img/sky.png', w: 1750, x: 540, y: 700, depth: .35, filter: 'saturate(.6)'});
A.add({img: 'img/hero_big.png', w: 600, x: 560, y: 1400, ax: .51, ay: .96, depth: 1, filter: LOOK.CUT});
A.add({img: 'img/cloud.png', w: 600, x: [[0, 900], [3, 560, 'lin']], y: 1260, depth: 1.5});   // 前景云，动得比人多

// 关键帧：[[时刻, 值, 缓动], …]；缓动写在到达的那一帧：io 慢推慢摇 / out 一般进场 / out5 快进慢停 / in 加速 / back 弹一下 / swing 吊牌摆停
// 注意：kf 的每一段都自带缓动，经过每个关键帧速度都归零——相机用它会"动一下、停一下"，像 PPT。相机用 spline（见下）。
```

**depth**：相机动时，depth 大的动得多（前景），小的动得少（远景）。底图 0.3–0.5，人和道具 1，前景云/手 1.3–1.8。
**叠放**：同一 depth 里先 add 的在下面。字要压在人身后，就先 add 字、再 add 人。场与场之间按 `scene({z})`，可以写小数（4.5 夹在 4 和 5 之间，引擎会换算成整数）。

一场里有三层盒子，从下到上：
| 盒子 | 放什么 | 怎么放 | 退场（irisOut）时 |
|---|---|---|---|
| back | 底色（scene 的 `bg`）和底图 | `add({img, back: true, …})` | 被圆裁成圆 |
| box | 人、道具、字（默认） | `add({…})` | 不裁，完整地跟着缩小 |
| pop | 必须压在最上面的：破框的主角、要盖住一切的贴条 | `add({…, pop: true})` | 不裁 |

**底图一定写 `back: true`**，否则退场时整张底图跟着缩成一个方块，不是圆。

`add()` 和 `word(..., {spec: {…}})` 里能写的字段：`x y s r o blur`（数字或关键帧）、`w h`（像素宽高）、`ax ay`（锚点，0–1）、`depth`、`back`、`pop`、`filter`、`css`（任意 CSS）、`cls`、`show: [出现, 消失]`、`update(t, L)`（每帧回调）、`sx`（横向缩放）。

## 相机：用曲线，不用一段段的缓动

```js
const {spline} = STAGE, h = 'h';
const Z = pts => spline(pts, {log: true}), P = pts => spline(pts);   // 缩放在对数空间插值
A.cam = {
  z: Z([[0, 1.32], [.9, 1.0, h], [2.0, 1.04], [2.4, 3.6]]),   // 拉开 → 停 → 一路加速推进画框（转场在最快处）
  y: P([[0, 40], [.9, 0, h], [2.4, -40]]),
};
```

- spline 经过中间关键帧时速度不归零（推完顺势拉）；`[t, v, 'h']` 表示在这一帧停住。
- 一场 1–2 个大动作：每个 0.8–2 秒、缩放 ×1.3–1.6；动作之间停（`'h'`）。参考片约 20–35% 的时间镜头几乎不动；中文版场长时更多（芒格第 6 版约 58%）。
- 转场放在动作最快处：出场的那段最后一个关键帧**不要停**（不写 `'h'`），速度带进转场。
- **到位的时刻 = 关键词的时刻**：`[at(句, 词) - .3, 起点, h], [at(句, 词) + .15, 终点, h]`。换场时刻也用 `at()` 取新画面要演的那个词，不用 `beat(句).start/end`（那是停顿）。
- 每个大动作起步处 `sfx(t, 'whoosh', -29)`，轻一点。
- 甩镜跨两场：上一场 `kf([[t-.3, 0], [t, 700, 'in']])`（加速），下一场 `kf([[t, -700], [t+.32, 0, 'out']])`（减速），切点 t 在钟形峰顶；`whips` 只标峰顶前后 0.1–0.2s。
- 快速扫过的物件（钞票、掉下来的纸、滑走的底）加 `mblur: true`，按它自己的速度加方向模糊。
- 自查：`vsr.py flow` 后 `vsr.py camcurve`，看图：要的是大起伏、平滑过零、中间有停；不要平线加转场处的尖刺。

## 字

```js
word(A, '1928', 540, -150, at('s01', '1928'), {kind: 'far', ax: .5, cls: 'orange', spec: {css: {fontSize: '230px'}, filter: LOOK.EXO}});
row(B, [['小镇', at('s03','小镇')], ['买不到', at('s03','买不到')], ['东西', at('s03','东西'), {cls: 'white'}]], 105, 700,
    {kind: 'rise', cls: 'red cn', spec: {css: {fontSize: '120px'}, filter: LOOK.EXR}});   // 一行按字宽排开
```

- `kind`：`pop` 弹一下（默认）/ `rise` 从下面升上来 / `far` 从远处飞近带模糊（年份、人名）/ `slide` 从一侧甩进 / `type` 逐字敲出（黑板）/ `scramble` 乱码解成字。
- `cls`（look.css）：`orange` 橙黄渐变（人名、年份）、`red` 暗红（处境）、`white` 重点词、`hot` 亮红（关键数字）、`ink` 浅底深灰、`label` 贴条、`chalk` 黑板字、`outline` 描边；中文加 `cn`（思源黑 Black 压窄到 0.86）。
- `LOOK`：`EXO` 橙字深红挤出、`EXR` 红字、`EXW` 白字、`EXK` 浅底深字、`CHALK` 粉笔发光、`LABEL` 贴条投影、`CUT` 剪纸投影。
- **`ax` 默认是 0（左端对齐）**：要居中写 `ax: .5`；`row()` 的整行对齐用 `align: 'center'`。
- `drift: .05`：字出现后慢慢变大（每秒 5%），让静止的字也在动。
- 字要压在人前面又不被相机推近放大：`spec: {pop: true, depth: .3}`（pop 盖在最上面；depth 小，推近时放大得少）。
- `until`：这个词消失的时刻（默认一直在，直到场结束）。
- 时间一律 `at(句id, '词')` 取，不手写秒数。改了文案或语速，画面自动跟上。

## 字幕（中文竖屏片默认要有）

```js
STAGE.captions({
  skip: ['s03', 's21'],                                    // 屏上已经写着这句的：片名卡、逐词排出来的原话
  breaks: {'他把会让人倾家荡产的蠢事列成一张清单': 12},    // 超过 14 字的，在语义处断（前半几个字）
  yield: [[at('s04', '芒格') - .3, at('s04', '牌') - .08]],  // 这段时间里开始的字幕推迟到段尾（镜头推近到名牌、大字时让位）
});
```

- 全片一条，单独一场（z 50），不跟相机走；按标点断成短句，每句在第一个字的读音时刻出现，下一句出现时换掉。
- 外观在 `look.css` 的 `.cap`：思源黑体 Bold 700、62px、白字 + 粗黑描边（下层黑字加 11px 描边，上层白字）+ 轻投影；**不做任何进场动画**——字幕是读的地方，关键词才表演。
- 位置默认 `x: 540, y: 1400`（9:16 抖音安全区，见 production.md 第 3 节）；`o.y` 可改。
- 超过 14 字又没写 `breaks` 的，会对半断并在控制台提醒；对半常常断在词中间，照提醒补上断点。

## 转场

```js
TX.irisIn(B, t0, .22, 560, 1060);      // 下一场从 (x,y) 的圆里长出来，0.22s 盖满（从主角胸口）
TX.irisOut(B, t0, .63, 540, 900, {w: 9, c: '#fff'});   // 这一场缩进白圈退场：只裁 back（底色、底图），人、道具、字完整地缩小，可以露在圈外
                                                       // 后两个参数 endScale=.55（画面缩到多大）、rEnd=390（收完时屏上圆的半径，px）
TX.porthole(C, t0, .3, 560, x, y, '#151515', tOpen);   // 黑色圆孔从外往里收，像镜头钻进一个圆窗（推近同一个东西）；tOpen 起往外张开，别等场结束突然消失
TX.ring(t0, t1, {r: [[t0, 1500], [t0 + .15, 690, 'out5']], x: 540, y: 972});   // 可动圆孔：r、x、y 可以是数字、关键帧或函数（圈从一角滑进来、第二次推近先张开再收回）
// 推过屏幕：框此刻在屏幕上的位置用上一场的相机算（z、cx、cy 取 tIn 时的值）
const z = camA.z(tIn), cy = camA.y(tIn);
TX.fromRect(B, tIn, .07, {x: 540 + z * (框左 - 540), y: 960 + z * (框上 - 960 - cy), w: 框宽 * z, h: 框高 * z});
```

- **上下顺序**：场按创建顺序叠，后建的在上面；要改就在 `scene({z: …})` 里写。irisIn 是**下一场在上面**（从圆里长出来）；irisOut 是**这一场在上面**（缩走后露出下面的下一场），所以 irisOut 的下一场 z 要更小。
- 擦过（物件从前景扫过、两边各露一个世界）：前景物件放在一个 z 最高的透明场里；下一场 `clip = t => 'inset(0 0 0 ' + 物件右边缘 + 'px)'` 只露在物件后面；上一场的 t1 要留到物件扫完。物件别宽过整屏，否则中间有一段整屏只有它（看着像黑了一下）。
- 硬切：两场 t1/t0 相接即可。只在"换气"之后、或者同一个底的舞台之间用。
- 物件扫过：就是一个大层从一边扫到另一边，扫到盖满屏的那一帧换场（下一场的 t0 = 盖满时刻）。
- 推过屏幕：用 `TX.fromRect`。上一场的相机只轻推（到 ×1.1 上下），下一场先缩在框里出现，0.07s 快进慢停放大到整屏，下一场自己的镜头接着推。不要把上一场的相机一路推到框盖满整屏再换——对临 v1 第一版就这么做，和原片差了一截（原片 1.15–1.22s）。
- 甩镜：见上面"相机"一节——跨两场的钟形（上一场加速出、下一场减速进），`whips` 只标峰顶前后那 0.14s 左右（只有这里加方向模糊）。

## 动作语法（acts.js）：每样东西怎么进、怎么动、怎么走

原创片最容易做成"半成品"：导演表写了每镜演什么，却没写东西怎么动，结果道具都"从零放大弹出来"或直线滑进来，到位就不动，人只是换一张姿势图（《商业狠人图鉴 01》第一版，用户："道具转场入场这些啥动画都没有""太偷懒了"）。对临做得好，是因为每个动作都从原片量了参数；原创没有原片可量，就**先写动作表，再写代码**：每个事件写清从哪进、走什么路、多久、缓动、过冲、模糊、碰到什么、怎么离场、到位后的小动作。

一条片里同一种语义用同一种动作，观众会读懂"砸下来的都是坏事"：

| 语义 | 怎么动 | acts.js |
|---|---|---|
| 坏事 | 从屏外 0.24s 加速**砸下来**，落地压扁 sy .9 再回弹；配 thud，相机震 10–16px，落点扬灰 | `drop(sc, spec, t)`、`shakeOf([[t, 14]])`、`dust(sc, t, x, y)` |
| 好事 / 翻盘 | 从下面 0.3s **弹上来**，过冲再回落，之后晃一晃 | `rise(sc, spec, t)` |
| 人名、地名、结论 | 贴条从 −40°、×1.7 **转着拍上去**，0.25s 快进慢停，小回摆 | `slap(sc, '文字', x, y, t, {size, r, cls, until})` |
| 甩进来的东西 | 0.12s 飞到位、带方向模糊，再阻尼摆 1s（角度 = A·e^(−2.5τ)·cos(7.2τ)） | 手写 `r: t => …`（对临 v1 的吊牌） |
| 人物换姿势 | 换图那一帧压扁一下（sy .91、横向 +3%）；平时有呼吸（±0.8%） | `actor(sc, [[图, 起, 止, {flip}], …], x, y, 身高)` |
| 走路 / 跑 | 上下颠 14px、12Hz（跑 17Hz）；往哪走就朝哪（`flip`） | `y: t => 脚 - Math.abs(Math.sin(t*12))*14` |
| 离场 | **从不凭空消失**：被推走、被风吹走、跟着戏里的人走、沉回地下；离场比进场快 | `x: plus(进场关键帧, out(t离场, 1500))` |
| 跟随 | 一样东西被另一样带走：位置 = 带它的那样东西的位置 + 偏移，晚 0.1s | `x: t => kf(她的x, t - .12) + 230` |

- `new_film.py` 建的工程已经载入 `a/acts.js`；`scene.js` 顶上 `const {person, actor, drop, rise, slap, dust, shakeOf, ring_, out, plus} = ACTS;`。
- 震屏加在相机上：`cam: {x: t => P(...)(t) + shakeOf(hits)(t), y: t => P(...)(t) + shakeOf(hits, 1.2)(t)}`。
- 同一个世界要画两遍（彩色 + 黑白压暗红）时，把这一场写成一个函数 `table(sc, gray)`，两个场各调一次，关键帧完全一样，只换滤镜；音效只让其中一遍登记。
- 验收看动作，不看静帧：每个事件前后 0.4s，按 0.05s 一帧排成帧条看（静帧拼图只能查构图和穿帮）。

## 音效登记

`word()` 和转场会自动登记默认音效（跳字 flick、打字每字 key、甩进 whip、圆圈 whoosh）。别的事件手动加：

```js
sfx(at('s04', '卖'), 'coin', -24);     // 金币飞走
word(..., {sfx: 'click'});              // 换成贴条的点击声；{sfx: false} 不出声
```

`node scripts/sfxlist.mjs --dir .` 把它们导出成 `sfx.json`（挨得太近的只留响的那个）。

## 坑

- look.css 的颜色类写在 **span** 上（`.chalk span{color:#f3f3ee}`、`.red span` 是渐变裁字）：自己写的 html 里只要外层带了这些类名，里面的 span 都会被它染色，外层再写 color 没用。自定义颜色就换一个类名，并且写到 span 上（对临 v1 的红色 80% 一直是白的，就是这个）。
- 侧脸的主角照片：老版 bighead.py 按脸框居中裁头，后脑勺和耳朵会被横着切掉；现在按眼睛那一行的人形轮廓裁。做完放在对比色底上看一眼头顶和后脑。

- `<script src="a/stage.js">` 要写在 `<body>` 里（它要往 body 里放舞台）。
- 一行字的宽度在字体加载后才量得准；`row()` 已经处理，自己量字宽要等 `window.ready`。
- 同一场里的层多于 ~40 个会变慢；一场就是一个小舞台，别把整片塞进一场。
- 图片太大（>3000px）会拖慢每帧截图，生图后缩到用得着的尺寸。
- 甩镜模糊只在 `whips` 窗里；普通摇镜、拉远不加模糊（参考片也没有）。
- `irisOut` 默认只裁底色；要整场一起裁，给场设 `cutoutsStay: false`。
