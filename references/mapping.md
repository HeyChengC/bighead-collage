# 映射：每类话怎么变成"实物在动"

写分镜、看着一句话不知道画什么时读这份。每条都有两个长得不一样的例子：一个来自参考片，一个是换了题目的推演（推演的不是标准答案，是同一判断在别的题目上的样子）。

## 分镜表格式

一句拆成几个**短语**（中文 2–8 字一个），每个短语一行：

| 时刻 | 短语 | 舞台（这一场的底和小世界） | 实物 + 动作 | 字（属于谁、怎么出） | 接上一镜的什么 | 音效 |
|---|---|---|---|---|---|---|
| 0.3 | 1928年 | 雾蒙蒙的伦敦屋顶（生图） | 镜头从烟囱上空往下摇 | "1928"橙黄挤出字从远处飞近，挂在天上 | —（开场） | flick |
| 1.0 | 伦敦 | 同上 | 大本钟的钟摆晃一下 | "伦敦"贴条拍在钟面上 | 同一个舞台 | click |

表写完先自查：每一行的"实物 + 动作"是不是这个短语的名词在做这个短语的动词？

## 一、人物登场

判断：大头剪纸站在一个**代表他处境**的小世界上；名字贴上去或从他身后升起。头约占全身 30%。

- 参考 v1 0.0s：巴菲特站在一台平板电脑的屏幕里（屏幕里是蓝天草地），平板放在铺满钞票、存折的桌上——"一个人 + 他的钱"一眼就有。名字是白底黑字的贴条，转着拍到屏幕角上。
- 参考 v2 0.5–2.4s：西尔斯站在一座浮空小镇上（小镇 = "小镇居民"），镜头从云上往下摇，他从画面下沿升进来；"Richard / Sears"两行橙黄大字从远处飞近，压在他身后。
- 推演（一位厨师）：大头厨师站在一口巨大的铁锅边沿上，锅里是他的餐厅模型；名字印在一张菜单上，菜单从上面落下来插在锅边。

不要：头像放在左下角加白边（`anchors/gap_pairs.jpg` 第一对）。人要整个站在世界上，世界要说明他是谁。

## 二、数字

判断：数字是一件实物上的字——人手里的牌子、黑板、卡片、计数器。数字变 = 换牌、敲字、一位位翻上来。关键数字换亮红。

- 参考 v1 1.3–2.0s：巴菲特举着一块灰牌"300"，"81"的红牌从上面翻下来盖住后两位，变成 381。牌子在他胸前，数字的大小被他的身体衬出来。
- 参考 v1 8.3–11.0s：黑板从墙上甩进来，"S&P 500"一个字一个字敲出来；圆孔推近，"WENT UP"发白光，"80%"红字从右边甩进来。
- 推演（"卖了 3 亿份"）：一摞唱片从下往上堆，每堆一层，顶上的计数牌翻一位。

不要：一个大数字单独砸在纯色底上（那是 PPT）；滚数可以用，但数字必须长在一件东西上。

## 三、时长 / 次数

判断：一个一个数出来，旁边有东西累加。

- 参考 v1 4.9–5.7s："one 1 → two 2 → three 3"，每个 0.27s，左边的红方块一个个加上去，右边小字 1、2、3 往下排。
- 推演（"等了七年"）：墙上的日历一页页撕掉，撕到第七页停住。

## 四、动作（卖、买、寄、等、拒绝……）

判断：动词在屏上真的发生，由道具或手来做。

- 参考 v1 6.6–7.4s："he's been selling"——金币从他身边往外飞走。
- 参考 v2 10.0–10.6s："send their order"——目录卡缩小飞进房子前的邮筒。
- 参考 v1 12.2–14.6s：别人在买 = 好几只手伸进来拿钞票；他在等 = 一只手平按在钞票上不动。**对比靠同一张桌面上的"动"和"不动"。**
- 推演（"他拒绝了这笔交易"）：一份合同推到他面前，一只手把它推回去，合同滑出画面。

## 五、处境 / 问题

判断：世界不换，处境变——同一个人、同一个小世界，去色压在暗红底上。圆从主角胸口长开，0.22 秒盖满。

- 参考 v2 2.4s：彩色的西尔斯和小镇 → 黑白的西尔斯和小镇在暗红上，"The People / In Small / Towns"三行压在他身后。
- 推演（"那一年他破产了"）：同一张办公桌，颜色抽掉，桌上的东西一件件被搬走。

只用一次。用两次以上就不是"变"了。

## 六、想法 / 办法

判断：深色底，一个发光的东西出现，字逐词出，最后它落到关键词旁。

- 参考 v2 6.6–7.9s：灯泡飞来飞去，"So He / Created / A Simple / Solution"，灯泡停在 Solution 旁。
- 推演（"他想到一个笨办法"）：一张折起来的纸条从口袋里弹出来展开，上面是那三个字。

## 七、提问 / 回答

判断：问题写在一件物件上，圆孔推近；回答是贴条一张张拍上去，带一点旋转后摆正。

- 参考 v1 14.7–15.9s："Why"红标贴在手心；"Because he's done / this before"两张贴条拍在手上。
- 推演（"为什么？"→"因为他算过"）：问号刻在一枚硬币上，翻面，背面贴着答案。

## 八、原话（他本人说的）

判断：话写在属于他的东西上，引号保留，人有一个动作对上"说"。参考片没有直接引语，下面是推演。

- 推演（"我没发明青霉素，是大自然发明的"）：他举着一块木牌，牌上是这句话；说到"大自然"，木牌后面的墙爬满藤蔓。
- 推演（"反过来想，总是反过来想"）：他倒挂着出场，说到"反过来"整个人翻正，字跟着他一起翻。

不要：对话气泡（漫画的语言，基线就是这么做的）；整句贴满屏。

## 九、转折（发现、变故）

判断：转折只演一次，演成"同一个世界换了状态"。变坏 → 去色压暗红；发现 → 镜头钻进那个关键物件（圆孔推近），里面的东西变了样。

- 参考 v2 2.4s：彩色的人和小镇 → 黑白 + 暗红。
- 推演（"培养皿上长了一块霉"）：圆孔推近那只皿，霉从一个点长开，周围一圈慢慢变透明。

## 十、人不在的时候

人物在场约占全片一半（v1 31%、v2 49%）。另一半由道具自己演：钞票扇过整屏（v1 3.9s）、计数板（v1 4.9s）、黑板（v1 7.5–11.7s）、手（v1 12.2–16.7s）、灯泡和目录（v2 6.6–10.0s）、房子和车（v2 10.0–12.4s）。
分镜写完数一下：主角在超过 70% 的时间里都在，就挑两三句把人拿掉，交给道具。

## 十一、什么时候不配新画面

同一场的后半句继续用上一句的舞台，只加字、推近或甩镜到同一个人的另一侧（v2 4.1s；v1 9.6s）。约每 2–3 句换一个舞台。全片舞台数 ≈ 时长 / 2 秒。

## 十二、拿不到的时候

- 主角的脸必须是真人（可授权的照片，或照照片生成的相像，标"AI 生成"）。没有可用照片：不做大头，改用剪影 + 名字贴条。
- 道具都可以生成：白底写实单品，生成后抠图。
- 历史场景：生成"微缩模型 / 移轴摄影"质感的东西比写实大场景更不容易露馅。但**小世界要从这个题目里找**：明信片、平板屏幕、桌面、模型、橱窗都行。参考片的浮空小镇是西尔斯那条的答案，不是默认答案；照搬它，盲看会一眼认出是照着做的。

## 十三、舞台调度：画面乱，多半是没分区，不是东西多

判断：一场先定几块**固定的位置**，每样东西只出现在它该在的那一块；该积累的排成一排留在原地，那一排就是递进；演完的小戏由戏里的人或下一件事带走；东西在台词说到它时才进场。不为了精简而精简：删东西治不了乱，分区和"凭什么留着、凭什么走"才治得了。

- 反例（《商业狠人图鉴 01》第二版）："烂过好几次"用了三张和后文无关的 2/7/3；每件坏事又各带一套道具（房子、筹码、眼镜、纸牌屋），都临时找个空位放，留到一阵风才一起吹走。用户："场景页面比较杂乱……为了堆砌而堆砌"。我先给每样东西机械地加退场，用户又打断："从导演的角度出发，而不是为了精简而精简"。
- 改法（第三版）：牌桌分三块——左 1/3 是主角；底部三个牌位（他先把三张牌扣在面前，一件坏事翻开一张，翻开的一直留着）；右上是小戏区（前妻带着房子走掉、耙子把钱带走、儿子的剪影等下一张牌翻开才散）。筹码最后从这三张烂牌上长出来：钱是从这手烂牌上长出来的。
- 推演（一个创业者三次失败）：桌上三个空的公司牌子位，每失败一次挂上一块写着公司名的牌子、被打上叉；第四次，同一排的最后一位挂上的牌子亮了。

| 区 | 放什么 | 什么时候走 |
|---|---|---|
| 主角位 | 主角，一直在，只换姿势 | 只有台词让他走才走（"换个人"就真的把他换走） |
| 账本位 | 会积累的东西，排成一排或一路的记号（牌、×、路碑） | 这一段的结论说完，整排一起被推走、被收走 |
| 小戏区 | 当前这件事的人和道具 | 戏演完由戏里的人带走；余波留到下一件事来 |
| 字位 | 这一拍的关键词 | 下一拍换掉 |

- 事情发生在人身上的，就演在他身上：54 岁失去左眼，镜头推到他脸上、镜片裂开，不放一副桌上的眼镜代替。
- 台词里的说法字面演出来常常最好懂："换个人早垮了"——把他拉出画面，换一个普通人站在同一排牌前倒下。

## 十四、角色：文案里提到的人都要上场

判断：文案里每个人都有一个角色演，不拿道具顶替人。主角准备 8–10 个姿势（被砸后仰、低头、握拳、指、抱臂、走、跑、举东西……），每 2–3 秒有一次表演变化。

- 主角的亲属这类真人：用背影或剪影（前妻提箱子的背影、九岁男孩的背影），不画长相。
- 群像（抄作业的人、牛市里抢钱的人）用普通比例的小纸人，不做大头。
- 反派、路人用虚构人物（紫西装的"烂人"、灰西装的普通人）。
- 首尾呼应可以靠一个配角：开头侧耳听的巴菲特，结尾又走进来侧耳听。
